# proyecto1

Cadena Justa:
Plataforma web de compra y venta de productos pesqueros y agropecuarios
El proyecto consiste en desarrollar una plataforma web transaccional que permita conectar directamente a pescadores, agricultores y compradores para la comercialización de productos pesqueros y agropecuarios de manera rápida, segura y organizada.
La plataforma permitirá que los productores publiquen sus productos disponibles, mientras que los clientes podrán navegar por el catálogo, realizar pedidos y coordinar entregas o puntos de recogida. El sistema estará orientado a pequeños productores de comunidades costeras y rurales que actualmente tienen dificultades para vender sus productos de manera digital y obtener precios justos.
El sistema será completamente navegable desde el navegador web y contará con autenticación de usuarios, gestión de productos, pedidos y pagos o registros de compra.
________________________________________
Problema que resuelve
En muchas comunidades pesqueras y agropecuarias, los productores dependen de intermediarios para vender sus productos, lo que reduce sus ganancias y limita el acceso directo a los clientes.
Además:
•	No existe una plataforma local organizada para ofrecer productos frescos. 
•	Los compradores no saben dónde encontrar productores confiables. 
•	Las ventas suelen realizarse de forma informal mediante llamadas o mensajes. 
•	Los productores tienen poca visibilidad de sus productos disponibles. 
La plataforma busca digitalizar este proceso y facilitar la conexión directa entre productores y consumidores.
________________________________________
Objetivo general
Desarrollar una plataforma web transaccional para la compra y venta de productos pesqueros y agropecuarios, permitiendo a productores publicar sus productos y a los clientes realizar pedidos de forma sencilla y segura.
________________________________________
Funcionalidades principales
Para productores
•	Registro e inicio de sesión. 
•	Publicar productos disponibles. 
•	Actualizar precios y cantidades. 
•	Gestionar pedidos recibidos. 
•	Ver historial de ventas. 
Para compradores
•	Registro e inicio de sesión. 
•	Buscar productos por categoría. 
•	Agregar productos al carrito. 
•	Realizar pedidos. 
•	Consultar historial de compras. 
Para administradores
•	Gestionar usuarios. 
•	Supervisar publicaciones. 
•	Controlar pedidos. 
•	Generar reportes básicos. 
________________________________________
Entidades principales del sistema
El sistema contará con al menos las siguientes entidades persistentes en la base de datos:
1.	Usuarios 
o	Datos personales 
o	Rol (comprador, productor, administrador) 
o	Correo y contraseña 
2.	Productos 
o	Nombre 
o	Descripción 
o	Precio 
o	Cantidad disponible 
o	Imagen 
3.	Categorías 
o	Productos pesqueros 
o	Productos agrícolas 
o	Productos pecuarios 
4.	Pedidos 
o	Fecha 
o	Estado del pedido 
o	Total de compra 
5.	Detalle_Pedido 
o	Producto 
o	Cantidad 
o	Subtotal 
6.	Pagos (opcional para ampliar) 
o	Método de pago 
o	Estado del pago 
7.	Reseñas o Calificaciones (opcional) 
o	Comentarios 
o	Puntuación 
________________________________________
Tipo de sistema
El proyecto corresponde a un sistema de información transaccional orientado a la web, ya que permite realizar operaciones de compra y venta en tiempo real mediante transacciones registradas en una base de datos.

Factibilidad del proyecto
El proyecto es viable para desarrollarse en equipo porque:
•	Puede dividirse en módulos (usuarios, productos, pedidos, administración). 
•	Utiliza tecnologías básicas y accesibles. 
•	Resuelve una necesidad real de productores locales. 
•	Permite implementar funcionalidades de forma progresiva. 
•	No requiere infraestructura compleja. 
________________________________________
Valor agregado
•	Impulsa el comercio local. 
•	Reduce intermediarios. 
•	Facilita el acceso a productos frescos. 
•	Promueve la transformación digital de comunidades rurales y pesqueras. 
•	Puede adaptarse posteriormente a aplicaciones móviles.
